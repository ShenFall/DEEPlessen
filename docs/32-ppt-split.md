# 32 PPT 分册脚本

> 2026-11-24 22:45。解决「单个课件超过 Cloudflare 25MB 上限」。
> 用本机 PowerPoint 自身拆分，**不是改 XML**，动画、母版、字体全部保留。

## 用法

**拖拽**：把 `.pptx` 拖到 `tools\拆分课件.bat` 上。

**命令行**：

```powershell
powershell -ExecutionPolicy Bypass -File tools\split-pptx.ps1 -Path "I:\DataSystem\地科\Capt 4_xxx.pptx"
```

拆整个目录（只处理超标的）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\split-pptx.ps1 -Path "I:\DataSystem\地科" -MaxMB 24
```

## 它做什么

1. 只读打开源文件，读出总页数
2. 按「目标体积 ÷ 平均页体积」估算每册页数
3. 用 `Slides.InsertFromFile` 按页段切成新文件
4. 若某册超限，页数减半重试，直到装得下
5. 命名 `原名 1-24页.pptx`、`原名 25-36页.pptx`……
6. 输出到 **桌面\深时分册\原名\**
7. 原文件**移到** `桌面\深时分册\_原文件\`（不删除，可随时拿回）
   - 加 `-KeepSource` 则原地保留

## 实测

| 文件 | 原体积 | 页数 | 结果 |
|---|---|---|---|
| Capt 2_矿物NEW | 63.8 MB | 82 | 4 册：7.0 / 16.0 / 21.9 / 19.4 MB |
| Capt 3_岩浆作用与岩浆岩 NEW | 89.7 MB | 79 | 7 册：12.6 / 23.6 / 23.2 / 10.9 / 8.5 / 6.8 / 4.1 MB |

页数核对无误（24+12+24+22=82；16+4+4+16+16+16+7=79）。

## 和学生端搜索的关系

分册名保留原文件名 + 页段，例如：

```
Capt 3_岩浆作用与岩浆岩 NEW 1-16页.pptx
Capt 3_岩浆作用与岩浆岩 NEW 17-20页.pptx
```

学生端搜索是**文件名子串 + 跳字 + 拼音首字母**，所以：

| 输入 | 命中 |
|---|---|
| `岩浆` | 7 册全部 |
| `17-20` | 第 2 册 |
| `yjzy`（岩浆作用） | 7 册全部 |
| `ppt` | 所有课件 |

**不需要改门户代码**，分册只是普通文件。

## 注意

- 需要本机安装 PowerPoint（已确认 16.0 可用）
- 拆分过程中会短暂启动 PowerPoint 后台进程，结束自动退出
- 一册可能小于上限很多（页面图片密度不均），这是正常的
- 单页本身就超过 25MB 时会提示「无法再拆」，那种页需要单独压图

## 拆分之后

1. 把 `桌面\深时分册\<原名>\` 里的分册**拖回** `I:\DataSystem\地科\`
2. 原超大文件已经在 `_原文件\`，不用再手动删
3. 重新跑 `tools\打包资料.bat`，此时三个 PPT 都会进包
