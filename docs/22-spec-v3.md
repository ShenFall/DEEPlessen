# 22 主规格书 v3（唯一真相源）

> 2026-11-23。替代此前所有版本。与本文冲突的旧文档以本文为准。
> 依据：`21-audit.md`（存量审计）、ADR-0008（本地库）、ADR-0010（Edge Only + 学生端轻量）。

## 0. 定位（一句话）

**这是一个人的行动看板：先看待办，再看资料；点名只是"收作业"这一类待办的执行页。**

不是班级管理系统，不是题库，不是统计大屏。

## 1. 边界

| 项 | 值 |
|---|---|
| 主要用户 | 你自己（1 人） |
| 次要用户 | 同班同学约 30 人（只读门户） |
| 部署 | 免费静态托管（无服务器） |
| 数据 | 浏览器 IndexedDB + 本地目录 `I:\DataSystem` |
| 本轮不做 | 多管理员、角色权限、公告发布、数据报表（P2 停车场） |

## 2. 两个应用（不是三个）

| 应用 | 目录 | 端 | 说明 |
|---|---|---|---|
| **管理端** | `app/` | 桌面 + 手机（同一套代码，响应式） | 看板、待办、作业清点、资料库 |
| **学生门户** | `student/`（待建） | 手机优先 | 只读课程资料，独立轻量构建 |

学生门户**不引 React**，纯 HTML/CSS/少量 JS，目标 < 30KB（ADR-0010）。

## 3. 信息架构：待办是一等公民

### 3.1 待办从哪来

| 来源 | 例子 | 生成方式 |
|---|---|---|
| 手动 | 「把第 7 章课件传到群里」 | 自己输入 |
| 作业 | 「数据结构 · 作业 5 还没收齐」 | **自动**：清点未收齐即存在一条 |
| 资料 | 「计网提纲还没发布」 | 自动：本地有文件但未发布 |

**关键规则**：作业派生的待办**不落库**，由清点状态实时推导。收齐了待办自动消失，避免两处状态打架。

### 3.2 页面

| 页面 | 路径 | 归属端 | 状态 |
|---|---|---|---|
| 看板 | `/` | A + B | 🔧 已有骨架，待办区需换成混合清单 |
| 待办（全部） | `/todos` | A + B | 🆕 新增 |
| 清点列表 | `/assignments` | A + B | ✅ |
| 对账台 | `/assignments/:id` | A + B | ✅（点名是这里的二级功能） |
| 资料库 | `/library` | A | ✅ |
| 学生门户 | `/c/:slug` | C | 🆕 |

### 3.3 看板结构（自上而下）

1. **一行状态**：日期 + 还剩 N 件
2. **现在要做**（主区，最多 5 条）：混合待办 + 作业派生项，按 逾期 → 今天 → 接下来 → 无时间 分组
3. **接下来**：未来 48 小时的截止
4. **资料**：已发布 N 个包 · M 个文件

## 4. 数据模型（Dexie v5 计划）

```ts
Todo {
  id: string
  title: string
  done: boolean
  due?: string          // ISO，可选
  createdAt: string
  doneAt?: string
  source: 'manual'      // 作业/资料条目由状态推导，不落库
}
```

现有四张表（students / assignments / submissions / publishes）**结构不动**。

关系：
```
assignments ─(未收齐)→ 推导出待办项（不落库）
todos ─(手动)→ 独立存在
publishes ─(本地有文件但未发布)→ 推导出待办项（不落库）
```

## 5. 设计 Token

### 5.1 共用基础（`tokens.css`，保留现有变量名）

| 变量 | 深空 | 纸白 |
|---|---|---|
| `--bg` | `#0F1620` | `#F7F4EE` |
| `--surface` | `#16233A` | `#FFFFFF` |
| `--cell` | `#1B3152` | `#FFFFFF` |
| `--line` | `rgba(242,237,228,.12)` | `#E2DCD1` |
| `--text` | `#F2EDE4` | `#1A1F2A` |
| `--dim` | `#9AA6B8` | `#6B7280` |
| `--mute` | `#5C6878` | ~~`#9A958C`~~ → **`#616875`** |
| `--gold` | `#D38A43` | `#B4762C` |
| `--amber` | `#E9A341` | `#8C5A20` |
| `--red` | `#E2603F` | `#C0432A` |
| `--signal` | `#4C7BE0` | `#2F5BD8` |

两处**必须修正**（当前不达 AA）：
- 纸白 `--mute` `#9A958C` = 2.71:1 → 改 `#616875`
- 纸白 `--amber` `#B4762C` = 3.44:1 → 文本场景改 `#8C5A20`

### 5.2 端级覆盖（只允许这几项不同）

| 变量 | 看板（A/B 首页） | 工作台（对账/资料/导入） | 学生门户 C |
|---|---|---|---|
| `--r-card` | 20px | 8px | 12px |
| `--r-ctrl` | 10px | 4px | 8px |
| `--panel-bg` | `rgba(21,41,75,.56)`（实色降级 `#101C2E`） | `var(--surface)` | `#FFFFFF` |
| 密度 | 宽松（行高 1.6，区块间距 20） | 紧凑（行高 1.4，间距 8） | 宽松（行高 1.7） |

**规则**：色值只有一套，端级只覆盖圆角、面板底、密度。不允许为某一端新增颜色。

## 6. 动画规格（代码可照抄）

| 动效 | 时长 | 缓动 | 数值 | 触发 |
|---|---|---|---|---|
| 页面切换 | 180ms | `cubic-bezier(.2,.8,.2,1)` | `opacity 0→1`，`translateY 4px→0` | 视图切换 |
| 面板入场 | 200ms | 同上 | `opacity 0→1`，`translateY 6px→0` | 首次挂载 |
| 列表逐条入场 | 每条 200ms，间隔 24ms | 同上 | 最多 8 条，超出部分直接显示 | 列表首屏 |
| 待办勾选 | 120ms | `ease-out` | `scale .98→1`，勾 `stroke-dashoffset 24→0` | 点击勾选 |
| 完成后文字 | 180ms | `ease-out` | 颜色 `--text → --dim`，不位移 | 勾选后 120ms |
| 面板悬停 | 120ms | `ease` | 边框 `rgba(255,255,255,.08)→.16` | 桌面 hover |
| 点名标记 | 220ms | `cubic-bezier(.2,.8,.2,1)` | 格子底色过渡；连点不排队 | 点击姓名格 |
| 骨架/加载 | 循环 2.4s | `linear` | 轨道旋转；**不人为延长** | 首次加载 |

**`prefers-reduced-motion: reduce`**：以上全部降级为 `opacity 120ms`，位移与缩放置零。

## 7. 开源选型（能不自写就不自写）

| 需求 | 决策 | 库 | 理由 |
|---|---|---|---|
| 待办拖拽排序 | **采用** | `@dnd-kit/core` + `@dnd-kit/sortable` | React 生态事实标准，~12KB，支持键盘 |
| 资料模糊搜索 | **采用** | `fuse.js` | 中英混排、拼音首字母容错，~5KB |
| 图标 | **采用** | `lucide-react` | 按需 tree-shake，风格统一 |
| Excel 解析 | 已用 | `read-excel-file` | 已经在用 |
| 离线 | 已用 | `vite-plugin-pwa` | 已经在用 |
| 组件库（shadcn/Radix） | **不采用** | — | 视觉由设计侧定制，整库会与 Token 打架 |
| 动画库（framer-motion） | **暂不采用** | — | 上表动效 CSS 可完成；只在拖拽重排需要时再引 |
| 日期库（dayjs） | **不采用** | — | 现有 20 行 `dueLabel` 够用，加库只为一个函数 |
| 虚拟滚动 | **不采用** | — | 30 人、几百个文件，不需要 |
| 状态管理（zustand） | **不采用** | — | 页面级状态足够，引入只会增加间接层 |

## 8. 建设顺序

| # | 任务 | 出口 |
|---|---|---|
| 1 | `todos` 表 + 看板待办区（手动新增、勾选、删除） | 能记三件事并打勾 |
| 2 | 作业派生待办 + 资料派生待办 | 收齐后待办自动消失 |

| 4 | 资料用途分类（讲义/作业/复习）+ fuse.js 搜索 | 记不住文件名也能找到 |
| 5 | 学生门户（静态 + manifest） | 手机能下载 |
| 6 | 免费托管部署 | HTTPS 下 PWA 可装 |
