## 0. 一句话

**把拾课从一个收作业工具，升级为 ShenFall 的个人运行系统：双星是品牌，轨道是图形语言，看板是首页，资料空间是对外的个人门面。**

关键词：`Orbital / Precision / Quiet luxury / Personal / Spatial`。

这里的「Apple 式」不是照搬苹果页面，而是借用它的方法：大留白、精确对齐、少量大字号、真实层级、细腻材质、动效有物理意义。

## 1. 三端分工

| 端 | 第一任务 | 首页 | 点名位置 | 气质 |
|---|---|---|---|---|
| 管理员桌面 | 掌握全局并快速进入处理 | `/dashboard` 大看板 | 作业模块二级页 | 深空、精密、信息丰富但不拥挤 |
| 管理员手机 | 看一眼状态、处理少数急事 | `/dashboard` 移动看板 | 作业 tab 内，不占首页主区域 | 清晰、快捷、低干扰 |
| 用户资料端 | 搜索并下载资料 | 个人资料空间 | 无 | 明亮、克制、有整理者个性 |

管理员桌面不再以「今日待办」为唯一首页；今日待办、DDL、资料热度、课程状态都并入看板。

## 2. 视觉系统升级

### 2.1 色彩：仍然只有蓝与金两种情绪

| 角色 | 建议值 | 用途 |
|---|---|---|
| 深空底 | `#070A12` | 桌面看板底色 |
| 深空提升 | `#0F1620` | 手机与强光环境 |
| 面板 | `rgba(21, 41, 75, .56)` | 大型看板卡，需有实色降级 |
| 面板实色 | `#101C2E` | 不支持透明度或低性能设备 |
| 主文字 | `#F2EDE4` | 标题与正文 |
| 次文字 | `#9AA6B8` | 标签与说明 |
| 轨道蓝 | `#4C7BE0` | 进行中、焦点、链接 |
| 归位金 | `#D38A43` | 完成、主按钮、个人印记 |
| 危机红 | `#E2603F` | 仅真正的 DDL 危机 |
| 纸白底 | `#F7F4EE` | 用户资料端 |
| 纸白文字 | `#1A1F2A` | 用户端正文 |
| 纸白次文字 | `#616875` | 已达 AA 的次级信息 |
| 纸白金 | `#8C5A20` | 用户端文本强调 |

空间渐变只允许出现在看板背景、Hero 和加载页：深空中心稍亮、边缘变暗，透明度低，不做彩色霓虹。内容卡片后方不放复杂图案。

### 2.2 字体：标题更像产品，数据仍像仪器

- 展示标题：系统黑体 / Inter / PingFang SC，字重 500，字距 `-.02em`。
- 中文正文：系统黑体；管理员表格可继续用更纱黑体。
- 数字、时间、快捷键：JetBrains Mono，`tabular-nums`。
- 全项目仍最多两套字体角色，不再增加装饰字体。

| 层级 | 桌面 | 手机 | 用途 |
|---|---|---|---|
| 展示标题 | 40 / 1.15 | 28 / 1.2 | 看板问候、资料空间主标题 |
| 页面标题 | 28 / 1.25 | 24 / 1.25 | 页面与大型卡片标题 |
| 卡片标题 | 15 / 1.4 | 15 / 1.4 | 卡片与列表标题 |
| 正文 | 13 / 1.6 | 13 / 1.6 | 管理员工具 |
| 用户端正文 | 15 / 1.7 | 15 / 1.7 | 文件名与公开说明 |
| 数据 | 24–32 | 24 | 关键数字，等宽 |

### 2.3 材质与形状

- 看板大卡圆角 20px，中卡 16px，小控件 10px；工作台仍保持 4–8px。
- 看板卡片用 `1px rgba(255,255,255,.08)` 边线；环境阴影只用于悬浮层和主 Hero，不给每张卡加发光。
- 玻璃效果只能作为轻微背景透光，正文后必须有足够实色；直接提供实色降级，不让可读性依赖 blur。
- 头像仍是 Logo；轨道线从头像向外延伸，形成个人识别，而不是另画一个无关的科技图标。

## 3. 管理员桌面端 `/dashboard`

### 3.1 布局骨架

以 1440px 为设计基准，内容最大宽 1600px；左侧 72px 导航，顶部 64px，主区 12 列网格，间距 20px。

```text
│ 通知    │ ┌──────────── 8 列：当前轨道 ────────┐ ┌ 4 列：下一 DDL ┐│
│ 日程    │ │ 双星轨道图 + 今日任务 + 一键进入     │ │ 倒计时 / 课程    ││
│ 花名册  │ └───────────────────────────────────┘ └───────────────┘│
│         │ ┌──── 3 列 ────┐┌──── 3 列 ────┐┌──── 3 列 ────┐┌ 3 列 ┐│
│         │ │ 待收作业       ││ 待发布资料     ││ 本周资料取用   ││ 已完成 ││
│         │ └───────────────┘└───────────────┘└───────────────┘└──────┘│
│         │ ┌──────── 7 列：课程运行状态 ────────┐ ┌ 5 列：资料热度 ───┐│

└─────────┴──────────────────────────────────────────────────────────┘
```

### 3.2 首屏不是数字墙

首屏只回答四个问题：

1. 现在最紧急的是什么？
2. 哪门课需要处理？
3. 哪些资料最常被要？
4. 下一步可以从哪里开始？

指标卡不堆无意义百分比。每个数字都必须能点击进入对应清单；没有下钻动作的统计不放在首屏。

### 3.3 卡片规格

| 卡片 | 内容 | 交互 | 视觉重点 |
|---|---|---|---|
| 当前轨道 Hero | 今日摘要、最近任务、双星轨道线稿 | 点任务进入处理 | 大号问候 + 右侧轨道，不做营销 Banner |
| 下一 DDL | 课程、作业、倒计时、欠交数 | 进入作业详情 | 倒计时等宽；危机时才出现红色 |
| 待收作业 | 收集中数量、最急一项 | 进入作业列表 | 蓝侧状态 |
| 待发布资料 | 本地未发布数量 | 进入资料库 | 金色只用于已完成，不滥用 |
| 资料取用 | 本周总量、变化趋势 | 进入资料统计 | 一条细趋势线即可 |
| 课程状态 | 6 门课、最近 DDL、欠交人数 | 按课程筛选 | 小倍图，不做巨大饼图 |
| 资料热度 | Top 5 文件与次数 | 复制链接 / 查看 | 横向细条 + 文件名 |
| 最近动态 | 标记、收录、发布、拆解 | 查看来源 | 一条时间线，最多 6 条 |
| 快捷入口 | 新建清点、收录资料、粘贴通知 | 直接执行 | 2×2 大按钮，手机可复用 |

### 3.4 桌面导航

`看板 / 作业 / 资料 / 通知 / 日程 / 花名册`，看板置首位。侧栏默认 72px，hover 或快捷键展开到 216px；对账台进入专注模式后仍可收起侧栏。

```text
┌ 下一节点 ────────────────────────────────┐
```

- 手机看板以只读聚合与轻操作优先，不出现库根选择、批量拖拽等桌面专属任务。

## 5. 用户资料端 · ShenFall 的个人资料空间

### 5.1 定位

不是通用文件列表，也不是个人博客。它应该像：**一个由 ShenFall 亲手整理、长期维护、审美统一的资料取件空间。**

主路径仍然是：搜索 / 选分类 → 点文件 → 下载。个人内容围绕主路径，不增加登录与无关页面。

### 5.2 首页结构

```text
[圆形头像 + 1px 轨道环]                     DEEP / 拾课

ShenFall 的资料空间
把零散课件、提纲与真题，整理成容易找到的样子。
—— 持续整理 · 最近更新于 11-22

[ 搜课程、章节或资料名称                              ]

[ 为你置顶 ]  [ 计算机网络 ]  [ 数据结构 ]  [ 更多课程 ]

┌ 精选：期末复习从这里开始 ──────────────────────────┐
│ 期末复习提纲 v3              12 页 · 2.4MB         │
│ 2025 期末真题                 8 页 · 1.1MB         │
└───────────────────────────────────────────────────┘

ZIP  数据结构实验参考           11-20

关于这个空间
由 ShenFall 整理。找不到资料，或文件失效，可以在群里 @我。
[ 个人主页 / 联系方式（可选） ]
```

### 5.3 「个人的东西」具体放什么

| 元素 | 内容 | 约束 |
|---|---|---|
| 个人印记 | 头像、「深」字、DEEP、个人一句话 | 使用真实头像，不生成替代人脸 |
| 整理者签名 | `ShenFall 整理 · 最近更新于…` | 每门课与文件详情都可出现 |
| 精选合集 | 「期末复习从这里开始」等人工置顶 | 由你维护，不做算法猜你喜欢 |
| 最近更新 | 最近 5 份资料 | 真实数据，不造假动态 |
| 关于空间 | 一小段整理原则、失效反馈方式 | 100 字以内 |
| 可选链接 | 个人主页、GitHub、联系方式 | 只放愿意公开的信息 |

视觉以纸白为主，顶部可有一块很轻的轨道线稿；头像与标题是个人识别，文件卡仍保持高可读、大点击区。科技感来自排版与动效，不把学生端变成深色黑客页面。

## 6. 品牌加载器 · Orbit Plotter

### 6.1 视觉与节奏

参考图的线条绘制感被转译成双星轨道绘图仪：

1. 轴线与三个虚线圆先以 360ms 淡入。
2. 中央连续轨迹在 900ms 内绘制完成。
3. 一颗金色小点沿轨道运行，周期 6s；虚线圆以 12s 缓慢旋转。
4. 文案使用 `正在加载仪表盘…`，不显示伪造百分比。
5. 数据就绪立即退出，150–220ms 淡出；绝不为了看完动画而延迟页面。

深色与浅色共用同一 SVG，通过 `currentColor` 换色。`prefers-reduced-motion` 下显示完整静态图与文字。

## 7. 动效语言

| 场景 | 动效 | 参数 |
|---|---|---|
| 看板首次进入 | 标题、Hero、卡片依次上浮淡入 | 360ms，间隔 40ms，只执行一次 |
| 卡片 hover | 上移 2px + 边线稍亮 | 160ms，仅精确指针设备 |
| 数字更新 | 旧值淡出、新值落位 | 180ms，不默认滚动计数 |
| 图表更新 | 细线绘制 / 条形长度变化 | 300–400ms，可降级为立即显示 |
| 页面切换 | 内容 8px 上浮淡入 | 180–220ms |
| 加载 | 轨道绘制 + 卫星运行 | 见第 6 节 |
| 收齐作业 | 一次金色落位 | 保留原设计，不叠加粒子 |

只动画 `transform`、`opacity` 和加载器必要的 SVG 描边；列表滚动时暂停非必要动画。低性能或减少动态时全部可静态呈现。

## 8. 响应式与无障碍

- 320px 起步；`<720` 手机，`720–1100` 平板，`>1100` 桌面，`>1440` 只增加留白，不无限拉大卡片。
- 桌面 12 列，平板 6 列，手机单列；Hero 与下一 DDL 在平板可并排，其余自然下落。
- 所有卡片标题、正文与关键数字达到 WCAG 2.2 AA；透明面板必须在实际背景上复核对比度。
- 图表同时提供文字数值，不用颜色作为唯一编码；趋势必须有涨跌文字或符号。
- 看板卡片若可点击，整卡使用明确链接或按钮语义；不把整段 `div` 伪装成按钮。
- 键盘焦点在看板深色与透明材质上都清晰可见；移动触控目标 ≥48px。
- 加载器为 `role="status"`，页面主内容加载后正确接收焦点；减少动态模式下无旋转与闪烁。

## 9. 素材与实现分工

- **另一个智能体负责**：看板概念稿、手机看板概念稿、个人资料空间概念稿、明暗两版轨道背景视觉。
- **前端直接实现**：Orbit Plotter 加载器、真实卡片、图表、响应式布局与所有交互；不要把生成图当最终 UI 使用。
- **生成图只负责视觉方向与氛围**：中文文字、数字、按钮与列表必须由真实 HTML 渲染，避免生图乱码进入产品。

具体需求已登记在 [16-assets-generation.md](16-assets-generation.md)。

## 10. 建议落地顺序

1. 先做 `/dashboard` 信息骨架与真实数据卡片，不等待任何生成图。
2. 实现 Orbit Plotter 与页面骨架屏，统一加载、空态、错误反馈。
3. 完成管理员手机看板的信息重排与底部导航。
4. 做资料端个人头部、精选合集、最近更新，保持搜索与下载路径不变。
5. 生成素材验收后，只替换 Hero 轨道背景与个人空间装饰，不重排已验证的界面。
