# 06 界面规格

标注方式：**区块 / 状态 / 键盘 / 文案**。没有写到的细节默认沿用 02-brand 的令牌。

## S1 今日 `/today`

| 区块 | 内容 |
|---|---|
| 顶栏 | 学期+班级下拉 ｜ `⌘K` ｜ 头像（带轨道环） |
| 主卡（唯一大卡） | 最近一个 DDL + 欠交人数 + 那个人的名字 + 三个动作 |
| 时间轴 | 未来 7 天，按「距今小时数」排，不按课程排 |
| 右侧窄卡 | 今天被要最多的资料 + 复制链接 |

**状态**

- 全部收齐：主卡变金边，文案 `[OK] 这一门齐了`，配一次 fall 动效，900ms 后自动收起成一行
- 有 DDL 且欠交：主卡红左边框（全站唯一的红）
- 今天没事：整页只用点阵背景 + 一行 `deep:~$ 今天没有欠账`

**键盘**：`1–5` 跳模块，`J/K` 切换时间轴条目，`Enter` 打开。

## S2 作业列表 `/assignments`

卡片列表，每张卡三行：

```
数据结构 · 作业 4                ● 1/40 未交
今晚 23:59 · 已收 39                 [ 对账 ]
────────────────────────────────────
```

- 卡片左边缘颜色 = 状态：红（欠交且 <24h）/ 琥珀（欠交，>24h）/ 金（收齐）/ 灰（已关闭）
- 按 DDL 升序，不按创建时间

**状态**：草稿（无 DDL）/ 收集中 / 对账中 / 已关闭。已关闭的卡片折叠成一行，可展开。

## S3 对账台 `/assignments/:id`（最重要）

布局：`180px 队列 | 1fr 矩阵`。见 05-flows B。

| 区域 | 规格 |
|---|---|
| 顶部 | 标题 + `已收 38 / 疑似 1 / 未交 1`，右侧 `粘贴名单` 主按钮 |
| 队列 | 等宽字体，每行 `符号 姓名 状态`，行高 28px，超过 8 人可滚动 |
| 矩阵 | 8 列 × N 行，格子 4px 圆角，高 30px，间距 4px |
| 底部 | 图例 `● 未交 ◐ 疑似 ○ 已交` + 键盘提示 + `Z 撤销` |

**格子三态**

| 态 | 视觉 |
|---|---|
| `unpaid` | 底 `--navy`，字 `--paper`，左 2px `--red`，字重 500 |
| `suspect` | 底透明，1px 虚线 `--amber`，字 `--amber`，前缀 `?` |
| `paid` | 底透明，字 `--mute`，`○` 前缀，整体 `opacity .45` |

**键盘**：`←↑↓→` 移动 · `Space` 切换 · `Z` 撤销 · `F` 聚焦搜索 · `Esc` 退出 · `⌘Enter` 完成对账。

**边界情况**

- 0 人未交 → 矩阵不动，只在顶部浮一行 `[OK] 齐了`，2 秒后淡出
- 全部未交（刚建卡）→ 提示 `先粘贴已交名单，或者直接点格子`
- 匹配率 <60% → 顶部黄条：`这次只认出 21/40，检查一下花名册或分隔符`
- 学生中途转班 → 学号消失时标 `inactive`，矩阵里留空位但灰掉，不删

## S4 资料库 `/materials`

两栏：左侧课程树（可折叠），右侧列表。

列表行：

```
[PDF] 计网 · 期末复习提纲 v3          12 页 · 2.4MB
      已发布 · 无口令 · 剩余 41 天     被取 23 次   [ 复制链接 ]
```

- `visibility` 用符号表示：`●` 已发布 / `◐` 有口令 / `○` 草稿 / `–` 已归档
- 支持拖拽到课程节点完成归类
- 顶部固定一行「本周被问 6 次」的榜单，按 `pickupCount` 排

## S5 通知 `/notices`

左侧收件列表（按时间倒序，未处理带 `●`），右侧详情 + 拆解结果。

- 拆解结果的卡片可以直接拖到时间轴
- 「疑似时间」用琥珀虚线框，点击弹出「这句话里的时间：下周三 → 2026-11-25」
- 已归档通知默认隐藏，可按老师筛选

## S6 日程 `/schedule`

周视图，7 列 × 24 小时网格。

- 图层开关在左上：`[ 我的 ] [ 班级 ] [ 全部 ]`
- 班级任务用金边，个人用蓝边，冲突时两张卡之间画一条虚线并标「重叠 2h」
- 点击空白格直接新建，只填标题就能存（不强迫你填完整）

## S7 花名册 `/students`

表格：姓名 / 学号 / 微信昵称 / 别名数 / 欠交次数 / 状态。

- 顶部：`导入` `导出 CSV` `+ 加一个人`
- 别名数 >0 的行，hover 展开显示具体别名，可删
- 欠交次数是这个表最有价值的列——期末评优、平时分都看它

## S8 导入向导 `/students/import`

四步：选文件 → 映射列 → 预览三态 → 确认。每步都有「上一步」，不丢已填内容。

## S9 学生端课程页 `/c/:slug`（纸白）

```
计算机网络
ShenFall 整理 · 更新于 11-18

[ 搜资料，输入课程或章节          ]

[全部] [课件] [提纲] [真题] [作业参考]

┌──────────────────────────────┐
│ PDF  期末复习提纲 v3           │
│      12 页 · 2.4MB · 11-18    │
└──────────────────────────────┘
...
找不到？在群里 @ShenFall
```

- 字号 15px 起，行高 1.6，点击区 ≥ 44px
- 搜索支持拼音首字母（`qwfx` → 期末复习）
- 点卡片直接下载，不做预览页（多一步就多跑一半人）
- 微信内置浏览器若拦截下载：兜底显示「右上角 ··· 用浏览器打开」+ 二维码

## S10 命令面板 `⌘K`

全站唯一的重度输入入口。支持：

| 输入 | 结果 |
|---|---|
| `ljh` / `嘉禾` / `林` | 跳到该学生，并高亮他在当前对账台的位置 |
| `2401` | 按学号找人 |
| `> 新建作业` | 执行命令（前缀 `>` 进命令模式） |
| `jw` | 跳到计网课程资料 |
| `?` | 显示全部快捷键 |

## 文案表

| 场景 | 文案 |
|---|---|
| 空 · 今日 | `deep:~$ 今天没有欠账` |
| 空 · 作业 | `这门课还没布置过东西` |
| 空 · 资料 | `先扔一份进来` |
| 全齐 | `[OK] 40/40，可以睡了` |
| 匹配率低 | `这次只认出 21/40，是不是换班了？` |
| 疑似 | `李梓衿 可能是 李子衿，确认一下` |
| 撤销 | `已撤销：林嘉禾 恢复为未交` |
| 学生端 404 | `这份资料已下线，问一下学委` |
| 口令错 | `口令不对，群公告里那条就是` |

禁止的文案：`暂无数据`、`操作成功`、`系统繁忙，请稍后再试`。
