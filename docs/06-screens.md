# 06 界面规格

标注方式：**区块 / 状态 / 键盘 / 文案**。没有写到的细节默认沿用 02-brand 的令牌。

## S1 今日 `/today`

| 区块 | 内容 |
|---|---|
| 顶栏 | 学期+班级下拉 ｜ `⌘K` ｜ 头像（带轨道环） |
| 主卡（唯一大卡） | 最近一个 DDL + 欠交人数 + 那个人的名字 + 两个动作：`标记已交` / `看历史` |
| 时间轴 | 未来 7 天，按「距今小时数」排，不按课程排 |
| 右侧窄卡 | 今天被要最多的资料 + 复制链接 |

**状态**

- 全部收齐：主卡变金边，文案 `[OK] 这一门齐了`，配一次 fall 动效，900ms 后自动收起成一行
- 有 DDL 且欠交：主卡红左边框（全站唯一的红）
- 今天没事：整页只用点阵背景 + 一行 `deep:~$ 今天没有欠账`

**键盘**：`1–5` 跳模块，`J/K` 切换时间轴条目，`Enter` 打开。

## S2 作业列表 `/assignments`

卡片列表，每张卡三行：

```
数据结构 · 作业 4                ● 1/40 未交
今晚 23:59 · 已收 39                 [ 对账 ]
────────────────────────────────────
```

- 卡片左边缘颜色 = 状态：红（欠交且 <24h）/ 琥珀（欠交，>24h）/ 金（收齐）/ 灰（已关闭）
- 按 DDL 升序，不按创建时间

**状态**：草稿（无 DDL）/ 收集中 / 对账中 / 已关闭。已关闭的卡片折叠成一行，可展开。

## S3 对账台 `/assignments/:id`（桌面版，最重要）

**这里的模型是 REPL，不是表格。** 见 05-flows B、ADR-0004。

> 手机版是另一套交互（4 列网格 + 自动前进 + 撤销 toast），见 [11-mobile.md](11-mobile.md)。两者共用数据，不共用布局。命令行只属于桌面。

布局：`命令行` / `160px 队列 + 1fr 矩阵` / `证据流`

| 区域 | 规格 |
|---|---|
| 顶部 | 标题 + `已收 27 / 40` + 剩余进度条（2px 金线，按比例） |
| 命令行 | `deep:~/ds-hw4$` + 输入框 + `⏎ 标记`。常驻焦点，在任何位置敲字都落进来 |
| 队列 | `QUEUE 13`，等宽，行高 28px，超过 7 人折叠成 `… 还有 6 人` |
| 矩阵 | 8 列 × N 行，格 30px，间距 4px，**学号顺序永不重排** |
| 证据流 | 最近 3 条：时间 · 姓名 · 来源（文件名 / 手动 / 接龙） |

**格子两态（流式场景只需要两态）**

| 态 | 视觉 |
|---|---|
| `unpaid` | 底 `--navy`，字 `--paper`，字重 500。**不加红边**——亮本身就是信号，13 个红边会很吵 |
| `paid` | 底透明，字 `--mute`，`opacity .35`，无前缀 |

`suspect` 从「格子层」移到「输入层」：敲进去的名字匹配不上时当场问「这是谁」，不给格子留黄边。流式场景每条记录都有人为动作，不需要事后猜。

**收尾态（剩 ≤ 2 人时自动切换）**

矩阵淡到 30% 并收起，中间浮出一张大卡：

```
还剩 1 人
林嘉禾
微信「一只眠羊」· 历史欠交 3 次
[ 标记已交 ]   [ 看历史 ]
```

不发催交话术——话要你自己说，产品只负责告诉你该跟谁说。

理由：前 39 次是流水线作业，最后 1 次是社交动作，界面必须换挡。

**键盘**：任意字符直接进命令行 · `⏎` 标记 · `↑↓` 在候选间选 · `Z` 撤销 · `Esc` 清空 · `⌘V` 尝试匹配剪贴板里的文件名

**边界情况**

- 0 人未交 → `[OK] 40/40`，矩阵落一次金，收成一行
- 文件名匹配不到人 → 命令行接管，列出「这是谁？」的候选
- 同一人标两次 → 不报错，只更新 `updatedAt`，证据流显示 `21:14 林嘉禾 · 重复提交`
- 中途关掉页面 → 本地即时落盘，回来还在
- 学生转班 → 标 `inactive`，矩阵留空位灰掉，不删

## S4 资料库 `/materials`

两栏：左侧课程树（可折叠），右侧列表。

列表行：

```
[PDF] 计网 · 期末复习提纲 v3          12 页 · 2.4MB
      已发布 · 无口令 · 剩余 41 天     被取 23 次   [ 复制链接 ]
```

- `visibility` 用符号表示：`●` 已发布 / `◐` 有口令 / `○` 草稿 / `–` 已归档
- 支持拖拽到课程节点完成归类
- 顶部固定一行「本周被问 6 次」的榜单，按 `pickupCount` 排

## S5 通知 `/notices`

左侧收件列表（按时间倒序，未处理带 `●`），右侧详情 + 拆解结果。

- 拆解结果的卡片可以直接拖到时间轴
- 「疑似时间」用琥珀虚线框，点击弹出「这句话里的时间：下周三 → 2026-11-25」
- 已归档通知默认隐藏，可按老师筛选

## S6 日程 `/schedule`

周视图，7 列 × 24 小时网格。

- 图层开关在左上：`[ 我的 ] [ 班级 ] [ 全部 ]`
- 班级任务用金边，个人用蓝边，冲突时两张卡之间画一条虚线并标「重叠 2h」
- 点击空白格直接新建，只填标题就能存（不强迫你填完整）

## S7 花名册 `/students`

表格：姓名 / 学号 / 微信昵称 / 别名数 / 欠交次数 / 状态。

- 顶部：`导入` `导出 CSV` `+ 加一个人`
- 别名数 >0 的行，hover 展开显示具体别名，可删
- 欠交次数是这个表最有价值的列——期末评优、平时分都看它

## S8 导入向导 `/students/import`

四步：选文件 → 映射列 → 预览三态 → 确认。每步都有「上一步」，不丢已填内容。

## S9 学生端课程页 `/c/:slug`（纸白）

```
计算机网络
ShenFall 整理 · 更新于 11-18

[ 搜资料，输入课程或章节          ]

[全部] [课件] [提纲] [真题] [作业参考]

┌──────────────────────────────┐
│ PDF  期末复习提纲 v3           │
│      12 页 · 2.4MB · 11-18    │
└──────────────────────────────┘
...
找不到？在群里 @ShenFall
```

- 字号 15px 起，行高 1.6，点击区 ≥ 44px
- 搜索支持拼音首字母（`qwfx` → 期末复习）
- 点卡片直接下载，不做预览页（多一步就多跑一半人）
- 微信内置浏览器若拦截下载：兜底显示「右上角 ··· 用浏览器打开」+ 二维码

## S10 命令面板 `⌘K`

全站唯一的重度输入入口。支持：

| 输入 | 结果 |
|---|---|
| `ljh` / `嘉禾` / `林` | 跳到该学生，并高亮他在当前对账台的位置 |
| `2401` | 按学号找人 |
| `> 新建作业` | 执行命令（前缀 `>` 进命令模式） |
| `jw` | 跳到计网课程资料 |
| `?` | 显示全部快捷键 |

## 文案表

| 场景 | 文案 |
|---|---|
| 空 · 今日 | `deep:~$ 今天没有欠账` |
| 空 · 作业 | `这门课还没布置过东西` |
| 空 · 资料 | `先扔一份进来` |
| 全齐 | `[OK] 40/40，可以睡了` |
| 匹配率低 | `这次只认出 21/40，是不是换班了？` |
| 疑似 | `李梓衿 可能是 李子衿，确认一下` |
| 撤销 | `已撤销：林嘉禾 恢复为未交` |
| 学生端 404 | `这份资料已下线，问一下学委` |
| 口令错 | `口令不对，群公告里那条就是` |

禁止的文案：`暂无数据`、`操作成功`、`系统繁忙，请稍后再试`。
