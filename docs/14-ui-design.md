# 14 UI 设计方案 · 组件层与关键界面

> 2026-11-22。基于 v0.7 设计基线，不重做品牌，不改变 01–13 已确定的产品判断。
>
> 这份方案补的是「令牌 → 组件 → 页面」中间缺失的组件层，并给出今日、对账台、学生取件页的可落地规格。

## 0. 设计判断

项目最鲜明的视觉资产不是「深色 + 金色」，而是三种秩序：

1. **双星秩序**：蓝侧表示仍在流转，金侧表示已经归位。
2. **答案秩序**：先看到「谁没交、现在要做什么」，再看到统计与历史。
3. **两套壳的秩序**：学委端高密、键盘优先；学生端低密、触摸优先。

因此 UI 不追求「科技感组件大礼包」，而追求：**安静的大面、精准的细线、少量的亮色、永远稳定的坐标。**

本方案遵守既有约束：无阴影、无玻璃拟态、无渐变铺底、圆角不超过 8px、功能层不使用装饰动效。

## 1. 页面视觉骨架

### 1.1 学委端 · 深空终端

- 页面底：`--void / #070A12`；手机深空使用 `#0F1620`。
- 内容面与页面底只拉开一级明度，不用阴影区分层级。
- 卡片用 `1px` 细线与 `8px` 圆角；内部格、输入框用 `4px`。
- 主文字 `--paper`，次级文字 `--dim`；金色只给主操作和完成态。
- 链接、焦点环、可交互文字统一 `--signal`。
- 全站只有「欠交且距 DDL < 24h」使用红色。
- 页面标题不放大做营销式 Hero；真正的视觉重心是名字、DDL 和下一步动作。

### 1.2 学生端 · 纸白取件柜

- 单列、最大宽 `560px`、居中；不使用学委端导航与终端符号。
- 卡片白底、细线分隔，文件名优先，元信息退后。
- 搜索与分类是唯一的查找工具；点卡片即下载，不加预览页。
- 不用深色模式强制覆盖学生端；以浅色、系统黑体、1.6 行高保证强光与微信内可读性。

## 2. 设计令牌补齐

现有 `tokens.css` 已有颜色和基础字号，建议只增量补齐，不改已有变量名。

### 2.1 尺寸与间距

采用 4px 基础单位、8px 主节奏；触控格等既有专业尺寸作为明确例外，不强行凑成 8 的倍数。

| Token | 值 | 用途 |
|---|---:|---|
| `--space-1` | 4px | 图标与文字、格子间距 |
| `--space-2` | 8px | 紧凑组件内部 |
| `--space-3` | 12px | 输入框、按钮水平内边距 |
| `--space-4` | 16px | 卡片内边距、组件间距 |
| `--space-6` | 24px | 页面区块间距 |
| `--space-8` | 32px | 大区块分隔 |
| `--control-h` | 36px | 桌面按钮与输入框 |
| `--touch-min` | 48px | 学委端手机触控目标 |
| `--topbar-h` | 44px | 顶栏 |
| `--rail-w` | 56px | 桌面窄侧栏 |
| `--content-max` | 1120px | 学委端内容最大宽 |
| `--reader-max` | 560px | 学生端内容最大宽 |

### 2.2 字体刻度

沿用 `11 / 12 / 13 / 15 / 20 / 28`，只使用 400、500 两档字重。

| 层级 | 字号 / 行高 | 用途 |
|---|---|---|
| 辅助 | 11 / 1.45 | 时间、来源、快捷键 |
| 次要 | 12 / 1.5 | 元信息、筛选、说明 |
| 正文 | 13 / 1.5 | 学委端默认正文 |
| 学生正文 | 15 / 1.6 | 学生端文件名与正文 |
| 答案 | 20 / 1.35 | 未交姓名、主卡标题 |
| 关键数字 | 28 / 1.2 | `27/40`、欠交人数 |

数字、人数、时间统一等宽字体与 `font-variant-numeric: tabular-nums`。中文标题字距 `.02em`，拉丁标题 `-.01em`。

### 2.3 层级与圆角

| 层级 | 值 | 用途 |
|---|---:|---|
| 内容 | 0 | 普通页面 |
| 吸顶 | 10 | 顶栏、筛选条 |
| 抽屉 | 20 | 未交抽屉、右侧待办 |
| 弹层 | 30 | 命令面板 |
| Toast | 40 | 撤销反馈 |

**需要对齐的一处不一致**：`02-brand.md` 规定圆角上限 8px，当前 `tokens.css` 的 `--r-lg` 为 10px。建议把 `--r-lg` 收到 8px；若 10px 是有意调整，应更新品牌文档并记录原因，不让两个规格长期并存。

## 3. 响应式与布局

| 断点 | 学委端 | 对账台 | 学生端 |
|---|---|---|---|
| `<720px` | 顶部 44px + 底部 4 tab；单列 | 全屏沉浸，无 tab | 单列，左右 16px |
| `720–1100px` | 两栏列表 / 详情；不用窄图标栏 | 队列可收为抽屉 | 单列，最大 560px |
| `>1100px` | 左 56px 栏 + 顶栏 + 主区 | 命令行 + 160px 队列 + 自适应矩阵 | 单列居中，不随屏幕拉宽 |

共同规则：

- 学委端主区 `max-width: 1120px; margin-inline: auto`，避免宽屏把视线拉散。
- 今日页桌面用 `minmax(0, 1fr) 280px`，右栏不足时掉到下方；其余页面默认单列。
- 主要操作落在手机下半屏；底部操作条加 `env(safe-area-inset-bottom)`。
- 任何筛选、标记、收齐动作都不得重排学号坐标。
- 桌面键盘与手机触摸是两套交互，不把桌面命令行压缩进手机。

## 4. 组件系统

### 4.1 核心组件清单

| 组件 | 必备状态 | 关键规则 |
|---|---|---|
| `Button` | 默认 / hover / focus / pressed / disabled / loading | primary 金、secondary 细线、ghost 无色；危险操作不默认红 |
| `IconButton` | 同上 | 必须有可访问名称；手机至少 48×48 |
| `Card` | 默认 / 紧急 / 完成 / 归档 | 仅用 2px 左边线表达状态，不整卡铺色 |
| `AssignmentCard` | 草稿 / 收集中 / 对账中 / 已关闭 | 三行结构；按 DDL 升序；已关闭折叠 |
| `StatusSymbol` | `● / ◐ / ○ / –` | 符号与文字并存，不仅靠颜色 |
| `ProgressLine` | 空 / 进行中 / 完成 | 2px 金线，带可访问的数值文本 |
| `FilterSegment` | 全部 / 未交 / 已交 | 选中用底线和字重，不用大面积填色 |
| `NameGrid` | 全部 / 筛选结果 / 收齐 | 学号顺序恒定；格子不重排 |
| `NameCell` | 未交 / 已交 / 按下 / 焦点 / 只读 | 真实 `button`；状态写入 `aria-pressed` |
| `NameListRow` | 未交 / 已交 / 长按菜单 | 一行一人，点行标记，长按恢复 |
| `Toast` | 普通 / 可撤销 | 底部拇指区上方；3.5s；不遮挡下一操作 |
| `Drawer` | 未交 / 待办 / 移动队列 | 非模态优先；支持 Esc 与焦点返回 |
| `EmptyState` | 无任务 / 无资料 / 无结果 | 点阵只在此处使用；一句人话 + 一个动作 |
| `SearchField` | 默认 / 输入 / 无结果 | 支持姓名、拼音首字母、学号后两位 |
| `CommandPalette` | 搜索 / 命令 / 快捷键 | 唯一重度输入入口；`>` 命令模式 |
| `FileCard` | 已发布 / 有口令 / 草稿 / 归档 / 失效 | 学生端点击直接下载，不做预览中间页 |

### 4.2 按钮规格

| 类型 | 视觉 | 用途 |
|---|---|---|
| Primary | 金底 `#D38A43` + 深字 `#1A1206` | 当前页面唯一下一步，如「标记已交」 |
| Secondary | 透明底 + `--line` 细线 | 「看历史」「复制链接」 |
| Ghost | 无底无边，文字 `--signal` | 低优先级导航 |
| Danger | 默认细线，确认时才出现红 | 删除、清空；不与 DDL 红混用 |

桌面高 36px，手机高 48px；主按钮不放大、不发光。hover 只改底色或边色，active 可 `translateY(1px)`，120ms 内完成。

### 4.3 姓名格：对账台的核心组件

建议把视觉差异放在**底与边**，不要把整个已交格子降到 `opacity: .28`。已交清单仍要核对姓名，强光下过低透明度会让名字不可读。

| 状态 | 底 | 边 | 姓名 | 其他 |
|---|---|---|---|---|
| 未交 | `--cell` | 1px `--cell-edge` | `--text`，500 | 亮格即答案，不额外加红边 |
| 已交 | 透明 | 透明或 `--line` | `--dim`，400 | 不再降低整体透明度 |
| 按下 | 略深一级 | 金色闪一次 | 不变 | 15ms 震动；220ms 内落位 |
| 键盘焦点 | 不变 | 2px `--signal` 外环 | 不变 | 不被格子裁切 |
| 离班空位 | 透明 | 1px 虚线 | `--mute` | 保留坐标，不可点击 |
| 已关闭 | 沿用交 / 未交 | 不变 | 不变 | 整组只读，不仅靠降低透明度 |

已交态仍可通过 `○`、背景与边线明确区分；颜色只是辅助，姓名可读性优先。

### 4.4 Toast 与撤销

- 位置：手机底部操作条上方 12px，桌面右下 24px。
- 内容：`已标记 陈知远` + `撤销`；撤销是真实按钮，不只是文字提示。
- 停留 3.5s；连续标记时更新同一条 Toast，不堆叠成一堵墙。
- 屏幕阅读器用 `aria-live="polite"`；连续快速标记时不要求逐条朗读全部历史。
- 收齐后 Toast 不抢主卡的 `[OK] 40/40` 完成反馈。

## 5. 关键界面设计

### 5.1 S1 今日 `/today`

**目标：打开就回答「现在最该处理什么」。**

桌面：

```text
┌ 顶栏：2026 秋 · 计科 2 班             ⌘K 搜索             头像 ┐
├──────────────────────────────────────────────────────────┤
│ 主卡（1fr）                                  右侧窄卡 280px │
│ 数据结构 · 作业 4                            本周最常被要     │
│ 今晚 23:59 · 还剩 1 人                       计网期末提纲 v3  │
│ 林嘉禾                                       被取 23 次       │
│ [ 标记已交 ]  [ 看历史 ]                     [ 复制链接 ]     │
│                                                          │
│ 未来 7 天                                                  │
│ 今天 18:00  计网实验报告        ● 3 人未交                  │
│ 明天 12:00  操作系统作业 2      ● 8 人未交                  │
└──────────────────────────────────────────────────────────┘
```

- 主卡只保留一个最近且最紧急的 DDL，不做多卡轮播。
- 欠交姓名用 20px / 500；`还剩 N 人` 用 28px 等宽数字。
- 欠交且 <24h：主卡左边线 2px 红；其余紧急程度用琥珀。
- 全部收齐：金边 + `[OK] 这一门齐了`，一次 fall，900ms 后收成一行；不自动跳页。
- 空状态：点阵 + `deep:~$ 今天没有欠账`，不硬塞统计图。

手机：主卡、时间轴、资料卡依次单列；主操作固定在主卡内部而非悬浮全屏，避免挡住时间轴。底部 4 tab 保持常驻，进入对账台后才隐藏。

- 自动前进默认开，标记后 300ms 只滚动到下一个未交，位移不超过一行；右下角可关。

## 6. 微交互参数

| 场景 | 参数 | 约束 |
|---|---|---|
| 按钮按下 | 120ms，`translateY(1px)` | 不缩放布局，不引发位移 |
| 标记落位 | 180–220ms，透明度 + `translateY(4px)` | 只动 transform / opacity |
| 筛选面板 | 160–180ms | 高度变化不带动整页跳动 |
| 收齐落金 | 240–400ms，一次 | 不循环、不发光 |
| Toast 进入 / 退出 | 180ms / 140ms | 停留 3.5s，撤销始终可点 |
| 自动前进 | 300ms 后触发，小距滚动 | 一次最多一行，可关闭 |
| 命令面板 | 160ms 淡入 + 8px 上浮 | 输入始终优先，字符逐显默认关 |
| 装饰动效 | 默认关闭 | 对账台永久禁入 |

`prefers-reduced-motion: reduce` 时 L2/L3 全关，L1 降为瞬时；功能反馈必须仍能通过文字和状态符号理解。

## 7. 无障碍核验与修正

以下为 WCAG 相对亮度实测，背景按页面底色计算。正文要求 4.5:1，大字与非文本 UI 要求 3:1。

### 7.1 已通过的关键组合

| 主题 | 前景 / 背景 | 对比度 |
|---|---|---:|
| 深空 | `#F2EDE4 / #070A12` | 16.97:1 |
| 深空 | `#8C97A8 / #070A12` | 6.70:1 |
| 深空 | `#4C7BE0 / #070A12` | 4.92:1 |
| 深空 | `#D38A43 / #070A12` | 7.05:1 |
| 深空 | `#E2603F / #070A12` | 5.63:1 |
| 手机深空 | `#F2EDE4 / #0F1620` | 15.58:1 |
| 手机格子 | `#F2EDE4 / #1B3152` | 11.20:1 |
| 纸白 | `#1A1F2A / #F7F4EE` | 15.02:1 |

### 7.2 必须修正的纸白组合

| 当前用途 | 当前值 | 对比度 | 建议 |
|---|---|---:|---|
| 文档中的次级文字 `--ink-dim` | `#6B7280` | 4.40:1 | 改为 `#616875`，达到 5.11:1 |
| 代码中的 `--dim / --mute` | `#9A958C` | 2.71:1 | 必要信息改用 `#616875`；低对比色只留真正禁用态 |
| 金色正文 / 链接 `--gold-ink` | `#B4762C` | 3.44:1 | 文本改为 `#8C5A20`，达到 5.32:1 |
| 金色边线 / 大图标 | `#B4762C` | 3.44:1 | 可保留，已过非文本 UI 3:1 |

建议新增 `--gold-text`，不要让同一个 `--gold` 同时承担装饰边和正文链接两种对比度职责。

### 7.3 交互无障碍

- 所有可点元素键盘可达；焦点环 `2px solid --signal`，外偏移 2px。
- 姓名格使用真实 `<button>`，用 `aria-pressed` 表示交 / 未交；可访问名称包含姓名和状态。
- 进度条使用 `role="progressbar"` 与当前值、最大值；不能只给一条金线。
- 命令面板与模态抽屉打开后管理焦点，Esc 关闭并把焦点还给触发元素。
- 状态不能只靠红 / 金 / 蓝区分，必须同时有 `● / ◐ / ○` 或文字。
- 学委端手机点击目标 ≥48px，学生端 ≥44px；相邻目标保留至少 8px 间隔。
- 已交、归档、离班姓名仍属于需要阅读的内容，不能用不可读的透明度敷衍过去。

## 9. 落地顺序

1. **先修令牌与基础组件**：纸白对比度、`--r-lg` 规格、间距、焦点环、Button / Toast / NameCell；不改变业务流程。
2. **从现有对账台反向抽组件**：把已经验证过的触控、筛选、撤销保留下来，避免另起一套样式。
3. **做今日页**：验证 AppShell、AssignmentCard、ProgressLine、EmptyState 能否覆盖新页面。
4. **做资料库 + 学生取件页**：这两页共用 FileCard，但分别验证深空高密与纸白低密两套皮肤。
5. **最后做通知、日程与花名册**：复用已稳定的表单、抽屉、表格和状态组件，不提前建设用不到的组件。

每一步都以真机可读、键盘可用、操作不重排为验收条件，而不是以「组件数量齐全」为验收条件。

## 10. 设计验收清单

- [ ] 首屏先给名字和下一步动作，不先给完成率图表。
- [ ] 学号位置在标记、筛选、撤销前后保持可预期。
- [ ] 红色只出现在真正的 DDL 危机或危险确认中。
- [ ] 所有正文达到 4.5:1；纸白 `--dim` 与金色正文已修正。
- [ ] 已交姓名仍可读，不依赖整体低透明度。
- [ ] 手机主要操作单手可达，目标 ≥48px，并避开底部安全区。
- [ ] 键盘能完成标记、撤销、筛选、关闭弹层，焦点始终可见。
- [ ] 状态同时使用符号或文字，不仅靠颜色。
- [ ] 对账台无壁纸、粒子、扫描线和其他装饰动效。
- [ ] 断网、空态、无结果、资料下线都有具体人话，不出现「系统繁忙」。
- [ ] `prefers-reduced-motion` 下所有功能仍可理解与操作。
- [ ] 学生端从打开链接到下载不超过两次点击。
