# 12 M0 施工计划（细分到可执行）

> 里程碑的粗粒度在 [10-tasks.md](10-tasks.md)。这里只细分**当前正在做的那一个**。
> M1 的细分等 M0 收官后再写，避免提前规划出纸上谈兵。

## 怎么跑起来

```bash
cd app
npm install
npm run dev      # http://127.0.0.1:5178
```

手机真机看效果：`npm run dev -- --host`，然后用手机访问电脑局域网 IP。**M0 的验收必须在真机上做**，DevTools 的模拟器测不出拇指距离和震动。

## 下一批（0.7–0.10）的取舍

- **0.7 和 0.8 是一对**：判定不做准，自动前进就会误标；所以必须一起做。
- **0.9 很便宜**，但做完之后每次调试都会带着旧状态，建议加一个「清空本地数据」的隐藏入口（长按标题）。
- **0.10 可以最后做**，它只影响"剩 1 个人"那一瞬间的体验。

## 已经踩到的环境问题

| 问题 | 现象 | 处理 |
|---|---|---|
| npm 官方源太慢 | 12 秒只下 600KB，装一次十几分钟 | `app/.npmrc` 指向 `registry.npmmirror.com`，快 9 倍 |
| Windows 证书吊销检查 | `git push` 报 `CRYPT_E_NO_REVOCATION_CHECK` | 用系统 git 加 `-c http.schannelCheckRevoke=false`；VS Code 内推送不受影响 |

## 这个阶段**不做**的事

放在 M0 里会拖慢验证，一律推迟：

- 路由（只有一个界面，不需要）
- 搜索与拼音匹配（M2）
- 真实存储与 Excel 导入（M1）
- PWA / 离线（M1）
- 桌面矩阵与命令行（M5+）
- 壁纸与装饰动效（M5）
