## 怎么跑起来

```bash
cd app
npm install
npm run dev      # http://127.0.0.1:5178
```

手机真机看效果：`npm run dev -- --host`，然后用手机访问电脑局域网 IP。**M0 的验收必须在真机上做**，DevTools 的模拟器测不出拇指距离和震动。

## 已经踩到的环境问题

| 问题 | 现象 | 处理 |
|---|---|---|
| npm 官方源太慢 | 12 秒只下 600KB，装一次十几分钟 | `app/.npmrc` 指向 `registry.npmmirror.com`，快 9 倍 |
| Windows 证书吊销检查 | `git push` 报 `CRYPT_E_NO_REVOCATION_CHECK` | 用系统 git 加 `-c http.schannelCheckRevoke=false`；VS Code 内推送不受影响 |

## 实现后修正（设计与真机的差异）

| 设计稿写的 | 真机跑出来的问题 | 改成什么 |
|---|---|---|
| 「自动前进：标记后滚到下一个未交」 | 28 格在整屏内放得下，**页面根本没有可滚动距离**，`scrollIntoView` 是空操作，功能等于不存在 | 改成**「指下一个」**：给目标加极细金线 + 角落圆点，视线自己跟过去；只有目标真的跑出屏幕才滚动 |
| 已交格子「透明底 + opacity .3」 | 连成一片时格子消失，网格看起来像缺了一块 | 加一层 `--paid-fill`（3.5% 白），保留网格形状，opacity 提到 .38 |
| 「未交」视图里标记后立即移除 | 下方所有人瞬间上移，快速连点时手指会落到别人身上 | 延迟 220ms 移除，先淡出再走 |
| 「自动指下一个」 | 学生是**随机**走上来交的，顺序引导指的人往往不在你面前，纯噪音 | 整条砍掉，位置让给常驻撤销（ADR-0009） |

## 这个阶段**不做**的事

放在 M0 里会拖慢验证，一律推迟：

- 路由（只有一个界面，不需要）
- 搜索与拼音匹配（M2）
- 真实存储与 Excel 导入（M1）
- PWA / 离线（M1）
- 桌面矩阵与命令行（M5+）
- 壁纸与装饰动效（M5）
