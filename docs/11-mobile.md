# 11 手机端：课堂现场

> 这一篇不是"手机适配说明"，是**主场景规格**。桌面版才是适配。

## 场景还原

周四下午第二大节，讲台上老师在等。你站在过道，学生一个个递作业过来。

- 一只手拿作业 → **只能单手操作**
- 学生报个名字就走 → **每次操作 2 秒内**
- 教学楼信号 1 格 → **不能等网络**
- 灯很亮，屏幕反光 → **深色会变镜子**

四条约束：单手可达、2 秒内、离线可用、强光可读。

## 布局

| 断点 | 布局 |
|---|---|
| `<720px` | 手机：底部 4 tab（今日 / 作业 / 资料 / 更多），顶部 44px 标题条 |
| `720–1100px` | 平板：两栏，左列表右详情 |
| `>1100px` | 桌面：56px 左栏 + 矩阵 + 命令行（见 06-screens） |

对账台在手机上是**全屏沉浸**，没有 tab，只有左上角返回。收作业时任何多余的东西都是干扰。

## 对账台 · 手机版

```
← 作业     数据结构 · 作业 4        27/40
━━━━━━━━━━━━━━━━━━━━█──────────────
● 离线 · 已存本地              21:07
[ 全部 ]  [ 未交 13 ]  [ 已交 27 ]

  林嘉禾    陈知远    王思睿    李子衿
  赵一诺    周予安    吴桐      郑亦舟
  孙时雨    何若谷    徐问渠    马星野
  ...

┌ 已标记 陈知远            撤销 ┐
[ 姓名 / 首字母 / 学号后两位 ]   [ 剩 13 ]
```

| 元素 | 规格 |
|---|---|
| 网格 | 4 列 × N 行，格子 70×50，名字 13px，最多 3 字 |
| 未交 | 底 `--navy` + 1px `rgba(233,163,65,.45)` 边 + 字 `--paper` |
| 已交 | 透明底，`opacity .28`，`scale(.96)` |
| 命中反馈 | 变暗 + 15ms 震动（Android）+ 金边闪一次（iOS） |
| **自动前进** | 标记后 300ms，视图滚到下一个未交（右下角可关，默认开） |
| 撤销 | 底部 toast 停 3.5s。**手机没有 Z 键，必须给可见的撤销** |
| 顶部计数 | `27/40` 常驻；点它展开未交抽屉 |
| 过滤 | `未交 13` 一键只看剩的人，剩 3 人时特别有用 |
| 快速定位 | 输 `09`（学号后两位）直接命中。29 人规模下，这是扫码签到的替代方案（见 ADR-0007）；两人后两位相同时列出候选 |
| 长按 | 菜单：标为未交 / 看历史 |

**为什么去掉命令行**：软键盘吃掉半屏，中文还要选字。课堂上最高效的是"看见就点"，不是"想起来再敲"。

## 强光与深浅

- 默认**跟随系统**：白天走「旧纸」（浅色），夜间走「深空」
- 深空在手机上提一档：底 `#0F1620` 而非 `#070A12`，纯黑在日光灯下会反成镜子
- 正文对比度 ≥ 4.5:1，进度条等纯视觉元素 ≥ 3:1
- 手动切换永远保留（系统判断在教室里不一定准）

## 离线

| 项 | 方案 |
|---|---|
| 壳 | PWA：manifest + service worker，"添加到主屏幕"，全屏无地址栏 |
| 数据 | 先写 IndexedDB，标记**永不等待网络** |
| 提示 | 顶部一行 `● 离线 · 已存本地`，联网后自动消失（不弹窗） |
| 冲突 | 单人使用，last-write-wins，不做合并 |
| 体积 | 首屏 ≤ 300KB gzip；Excel 解析器 900KB 动态 import，只在导入时下载 |

**教室没网是常态，不是异常。** 任何"网络错误"提示在这个产品里都算 bug。

## 触控细节

- 点击目标 ≥ 48×48，格子 70×50 已满足
- `touch-action: manipulation`（禁双击缩放）、禁下拉刷新（会误触丢状态）
- 点击判定：位移 < 8px 且时长 < 300ms，区分滚动与点击
- 底部操作条固定在拇指区，避开 iOS 底部的横条安全区（`env(safe-area-inset-bottom)`）
- 不允许 `alert()` / 全屏弹窗，一律用 toast 或抽屉

## 桌面的角色

不是"另一套功能"，是**另一个时段**：

| 场景 | 设备 | 交互 |
|---|---|---|
| 课堂收作业 | 手机 | 网格、点、自动前进 |
| 晚上补录 / 批量粘贴 | 桌面 | 命令行、矩阵、多选 |
| 发资料 / 看统计 | 桌面 | 拖拽、表格 |

命令行和 8 列矩阵**只属于桌面**，不进手机。反过来，手机上也不需要看到壁纸和装饰动效（见 09 的 L3 禁入规则）。

## 手机端也要防的两件事

1. **误标**：格子大、有撤销、自动前进可关。三条一起才够。
2. **视线离开**：自动滚动的位移要小（一次一格），不要"跳"到屏幕另一头，否则你不知道自己标到哪了。
