# 09 外观层与动效分层

## 结构不可换，皮肤可换

品牌是固定的（双星、深空、等宽字），外观是可换的（壁纸、强调色、密度）。
把这两件事混在一起，结果就是「换个壁纸把品牌换没了」。所以先分层，再谈自定义。

| 层 | 是否可被用户覆盖 | 内容 |
|---|---|---|
| 结构 | 否 | 栅格、间距阶梯、圆角上限、字号阶梯、信息密度逻辑 |
| 色彩 | 是 | `--void` `--deep` `--navy` `--blue` `--signal` `--gold` `--paper` `--dim` `--mute` |
| 材质 | 是 | `--wallpaper` `--scrim` `--blur` `--grain` |
| 动效 | 是（分层开关） | L1 / L2 / L3 |

## 壁纸规则

1. **壁纸不铺内容区。** 只出现在四个地方：登录页、空状态、侧栏底部 96px 窄条、命令面板背后。
   理由很硬：40 格矩阵 + 壁纸 = 不可读。信息密度高的界面必须给眼睛一块安静的底。
2. **可读性守门。** 应用壁纸时自动计算正文与背景的对比度，低于 4.5:1 就强制叠加 scrim（遮罩），滑杆 0–80% 可调，但**不允许关到 0**。宁可丑一点，不能看不清字。
3. **自动处理。** 上传后等比裁切、压到 2400px 宽、生成 8px 模糊小图做占位，避免首屏闪。
4. **视差默认关。** 30s 一个来回、位移 ≤2%，属于 L3。

## 预设主题

| 名称 | 底 | 强调 | 气质 |
|---|---|---|---|
| 深空（默认） | `#070A12` | 金 `#D38A43` | 就是那张头像 |
| 极光 | `#060B10` | 青 `#3FBFA0` | 冷、亮、像老终端 |
| 墨黑 | `#0A0A0A` | 白 `#EDEDED` | 纯文字，最省眼 |
| 旧纸 | `#F3EEE3` | 赭 `#A2662F` | 白天用，浅色 |
| 自定义 | 取壁纸主色 | 自动建议 | 你的图 |

自动取色：从壁纸采样主色 → 转 HSL → 把 S/L 钳到可用区间（保证对比度）→ 出 3 档强调色候选，你挑一个。

## 动效三层

| 层 | 内容 | 时长 | 可关 | 默认 |
|---|---|---|---|---|
| **L1 功能** | 标记落位、面板开合、焦点移动、进度条 | 120–220ms | 不可（可降为瞬时） | 开 |
| **L2 状态** | 收齐落金、剩 1 人换挡、撤销回弹 | 240–400ms | 可 | 开 |
| **L3 装饰** | 星尘粒子、光标拖尾、壁纸视差、字符逐显、扫描线 | 400ms–30s | 可 | **关** |

三条铁律：

1. **L1 永不超过 250ms，且不阻塞输入。** 深夜连标 40 个人，动画慢 100ms 就是 40 次不爽。
2. **L3 只出现在「没有任务等你」的地方。** 对账台上不许有粒子——那是在你数人时往你眼前撒星星。空状态、收齐后、首页顶部，随便华丽。
3. `prefers-reduced-motion` → L2/L3 全关，L1 降为瞬时。

## 动效包

三档，用户自己选，存在本地：

- **静默**：只有 L1
- **标准**（默认）：L1 + L2
- **华丽**：L1 + L2 + L3 全套

「华丽」必须有一份具体清单，否则实现时一定演变成「到处乱动」：

| # | 场景 | 效果 | 时长 |
|---|---|---|---|
| 1 | 收齐 40/40 | 金色粒子从每个格子位置升空，散开消散 | 2.2s |
| 2 | 切页 | 内容 8px 上浮淡入，侧栏指示条滑动 | 180ms |
| 3 | 壁纸 | 极慢视差，位移 ≤2% | 30s 循环 |
| 4 | 命令面板 | 背后星点视差，输入字符逐显 | 40ms/字 |
| 5 | 剩 1 人换挡 | 矩阵向心收缩，大卡从中心展开 | 420ms |
| 6 | 悬停头像 | 轨道环加速至 2s 一圈 | — |

**性能纪律**：只动 `transform` / `opacity`；列表滚动时暂停 L2/L3；持续 FPS < 50 自动降一档。

## 密度与字体

- 密度三档：紧凑 / 标准 / 宽松（影响行高 26/30/34px 与矩阵列数 10/8/6）
- 字体可选：等宽（默认）/ 黑体 / 衬线数字
- 字号阶梯不可改。改了就不叫「可自定义」，叫「可自我毁灭」。

## 明确不做

- 不做动效编辑器
- 不做主题市场 / 社区分享
- 不做背景音乐
- 不做「自定义圆角」这类会破坏对齐的选项
