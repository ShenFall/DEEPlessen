## 关键技术决定

1. **不做后端**：数据在本地 IndexedDB + 磁盘目录，三端各自成体系，靠导出备份搬运
2. **不用对象存储**：门户是静态导出，绕开收费与备案
3. **不做拖拽排序**：按截止自动分组，够用
4. **详情一律弹层**：待办、作业都用底部卡片
5. **模糊搜索自研**：子串 → 跳字 → 扩展名 → 拼音首字母（用 zh 排序锚字推首字母，零词典）
6. **手机统一纸白**：切 tab 不再黑白跳变；深空仅保留桌面看板

## 踩过的坑（今天新增）

1. `sticky` + 改高度 → 文档高度变化 → scrollY 被夹回 → **抽搐回弹**；改 `fixed` 解决
2. 正则删 CSS 留下未闭合 `@media` → 后续规则全被吞 → 页面变裸 HTML；**改模板后必须校验花括号**
3. 边缘检测不适合厚涂插画 → 线稿化失败；改灰度+阈值，或干脆放弃
4. `absolute + z-index:0` 会盖住静态内容 → 背景层要用 `z-index:-1`
5. 旧 Service Worker 自动接管导致**页面反复刷新**；开发环境注销 SW
6. 本机 TLS 拦截导致 `git push` 失败（schannel 吊销检查）→ 推送交给用户本机执行
