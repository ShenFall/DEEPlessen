## 今天踩过的坑（都已修）

1. 28 格整屏放得下时 `scrollIntoView` 是空操作 → 放弃"自动前进"
2. 已交格透明底让网格看起来缺块 → 加 3.5% 底色
3. "未交"里标记后立即移除，连点会打到别人 → 延迟 220ms 淡出
4. 长按会选中文字 → `user-select: none` + 拦截 contextmenu
5. 返回按钮只有 12px 箭头可点 → 整块按钮
6. 名单人数变了但作业 `total` 不变 → 启动时同步
7. Service Worker 只在 HTTPS/localhost 注册 → 局域网 IP 上手机永远白屏
