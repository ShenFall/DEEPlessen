# 05 核心流程

## A. 建档：导入花名册（一学期一次）

```
新建班级 → 选学期 → 导入文件 → 列映射 → 预览三态 → 确认 → 生成 40 个 student
```

- 触发：首次进入，或 `/students/import`
- 失败处理：
  - 编码错 → 提示切换 GBK/UTF-8，给一份原始前 5 行的十六进制预览
  - 表头识别不到 → 手动点选列，记住映射
  - 重名 → 阻断，要求补学号
- 完成后：立刻生成一个 4 位班级码，用于后续分享链接的归属

## B. 对账点名（核心，每周 3–6 次）

**重新设计了。不是「点一下名字然后消失」。**

### 真实动作拆解

学委收作业从来不是「逐个点名」，而是**手里已经有一份「谁交了」的名单，需要和花名册做差集**。这份名单可能是：

1. 群里的接龙（一段文字）
2. 网盘文件夹里的文件名列表（40 个 `姓名-学号.pdf`）
3. 学习通/雨课堂的已交名单（可复制）
4. 纸质作业（只能手点）

前三种占了 90%。所以主操作是**导入对账**，手点只是兜底。

### 流程

```
作业卡 →「对账」
  ↓
① 粘贴/拖入已交名单（支持多段混合粘贴）
  ↓
② 自动识别分隔符，切出 N 条候选
  ↓
③ 逐条匹配（见 04 的算法），产出三态
  ↓
④ 预览：已交 38 / 疑似 1 / 未交 1 / 未知 0
  ↓
⑤ 只处理「疑似」和「未知」，其余一键确认
  ↓
⑥ 生成欠交清单 → 复制催交话术 / 标记完成
```

### 界面结构（对账台）

两栏，各司其职，**互不重排**：

**左栏 · 队列（180px）** — 这是一个真正的待办队列，可以消失。

```
待收 2 / 40
────────────────
▸ 林嘉禾        未交
◐ 李梓衿        疑似
────────────────
⌘ 全部标记完成
```

**右栏 · 矩阵（1fr）** — 学号顺序，永不重排。

```
[林嘉禾] [陈知远] [王思睿] [李子衿] ...
   ●        ○        ○        ○
```

### 关键交互规则（ADR-0002）

| 规则 | 说明 |
|---|---|
| 点一下**不消失** | 只从 `●` 变成 `○`，底色变暗、字变 `--mute`、加 4px 下移。**坐标不动** |
| 再点一下**复原** | 可逆。误操作的成本是 0 |
| 位置按学号固定 | 不允许「未交优先」排序。你熟悉花名册的顺序，那是肌肉记忆 |
| `Z` 撤销 | 最近 20 步，带 toast 提示 |
| 拖框多选 | 线下收纸质时，一片一片勾 |
| 已交的人**留在原地** | 你能看到「这一排都交了」的空间感，这比列表干净更重要 |

## C. 通知拆解

```
/notices → 粘贴框（Cmd+V 直接落进去）
  ↓
拆成 1–N 张任务卡，每张带：
  · 课程（自动上色）
  · 绝对时间（原文是「下周三」→ 换算成 11-25 23:59，并标注换算依据）
  · 置信度（确定 / 待确认 / 需你补时间）
  · 原文锚点（点一下高亮回原句）
  ↓
可编辑：拖一下改时间，改完记住这位老师的措辞
  ↓
落到时间轴 + 相关作业卡自动关联
```

失败处理：一句通知拆出 0 条 → 不硬拆，保留原文并提示「这条可能不是任务，要不要归档？」。拆出 5 条以上 → 折叠成「这条里有 6 件事，展开看」。

## D. 发布资料到学生端

```
/materials → 拖入文件（可批量）
  ↓
自动清洗文件名：计网复习提纲v3(1)最终版.pdf → 计网 · 期末复习提纲 v3
  ↓
自动打标：课程（从文件名猜）/ 类型（从后缀和关键词猜）/ 章节（可空）
  ↓
发布设置：公开 or 口令 | 有效期（默认学期末+7 天）
  ↓
生成：短链 / 二维码 / 一段可直接发群的文案
  ↓
学生侧：/c/<course> 或 /p/<slug>
```

**发群文案模板**（一键复制）：

```
【计网】期末复习提纲 v3 已上传
→ deep.shenfall.dev/c/jw
口令：无
找不到就在群里说一声
```

## E. 换班级 / 换学期

```
新班级 → 导入新花名册（走 A）→ 复制上学期课程结构 → 完成
旧班级自动 archived，历史数据只读保留
```

不做的：不做数据迁移工具。因为数据结构从一开始就按 `cohort + semester` 分好了，不需要迁移。

## F. 一天的真实使用（用于校验设计）

| 时间 | 动作 | 界面 | 期望耗时 |
|---|---|---|---|
| 08:20 | 看一眼今天要交什么 | 今日 | 3 秒 |
| 12:30 | 老师群里发通知 | 通知 · 粘贴 | 15 秒 |
| 21:40 | 收作业，群里接龙结束 | 作业 · 对账 | 40 秒 |
| 21:45 | 还剩 2 人，私聊催 | 复制话术 → 微信 | 20 秒 |
| 23:10 | 有人补交 | 对账台点一下 | 2 秒 |
| 23:30 | 有人问复习提纲 | 复制取件链接 | 5 秒 |
