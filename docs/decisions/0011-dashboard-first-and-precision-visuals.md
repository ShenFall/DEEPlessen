# ADR-0011 仪表盘优先与精密视觉升级

- 状态：已采纳
- 日期：2026-11-22
- 相关：ADR-0005（动效分层）、ADR-0006（手机优先）、ADR-0010（学委端 Edge Only）
- 局部取代：03 的导航优先级、06 的 S1 首页定位、14 的今日页布局；对账台内部规则不变

## 背景

产品最初围绕「课堂上快速收作业」组织界面，首页是今日待办。随着资料库、发布、统计能力补齐，管理员需要一个能总览班级运转的首页，而不是打开就进入单一任务。

新的产品优先级：

- 管理员桌面端：大看板是首页与主要工作区，点名是其中一个工具。
- 管理员手机端：仍以看板为首页，用于掌握状态与轻量处理，点名不是首页主角。
- 用户资料端：不仅检索文件，也要体现 ShenFall 的个人整理者身份与审美。
- 视觉从「纯终端」升级为「精密、克制、有材质感的个人驾驶舱」，参考 Apple 式高级感，而非泛赛博朋克。

## 决策

### 一、Dashboard First

管理员桌面与手机的首页均为 `/dashboard`。原 `/today` 的待办与最近 DDL 并入看板，不再单独竞争首页。

点名 / 对账仍在作业模块内保留完整能力；课堂上的位置恒定、离线、撤销、快捷标记等规则全部不变。

### 二、两种视觉密度，不再只有两种皮肤

- **驾驶舱**：用于管理员看板、空态、加载与个人展示。允许大圆角、细腻空间渐变、少量环境阴影、轨道线稿与分层动效。
- **工作台**：用于对账、导入、表格、编辑。继续遵守细线、低装饰、圆角不超过 8px、功能动效克制。

高级感的来源依次是：排版、留白、比例、材质、动效；不是增加颜色与发光。

### 三、品牌加载器改为 SVG 轨道绘图

参考 2026-11-22 的加载页截图，使用细线、虚线圆、轴线与一条连续轨迹组成「轨道绘图仪」。加载动画由 SVG + CSS 实现，不生成静态替代图，不为了展示动画人为延长等待。

`prefers-reduced-motion` 下显示静态轨道与文字。加载动画属于品牌反馈，不进入对账台内的连续标记操作。

### 四、管理员手机端是看板，不是桌面文件管理器

管理员手机端允许查看聚合状态、最近动态、资料热度，并进入既有轻量操作；不要求 File System Access API，不承担本地库根选择与批量文件管理。

本 ADR 不授权把真实花名册或欠交明细默认上云。手机看板的数据源与同步边界另行设计；在确定前，界面按只读聚合快照与本地缓存设计。

### 五、资料端升级为个人资料空间

保留「不注册、搜索、分类、直接下载」的效率，同时增加头像、整理者签名、精选合集、最近更新与可选个人链接。个人内容只放公开信息，不影响文件查找主路径。

## 后果

- 首页信息架构与导航需要调整，原今日页不再是独立主页面。
- 看板可使用更丰富的视觉语言，但工作台仍保持原有可读性与操作纪律。
- 管理员手机端与 ADR-0010 的桌面 Edge Only 边界被局部打开；完整桌面管理能力仍只在 Edge 桌面提供。
- 需要一套可复用的 SVG 加载组件与少量品牌视觉素材，而非大量装饰图片。

## 否决方案

| 方案 | 否决理由 |
|---|---|
| 全站统一改为玻璃拟态、霓虹科技风 | 会失去双星识别度，并伤害对账与表格可读性 |
| 手机首页直接放完整点名矩阵 | 与新的看板优先方向冲突，也浪费首屏 |
| 加载动画做成视频或生成图片序列 | 体积大、不可控、弱网体验差；SVG 更清晰 |
| 资料端改成个人社交主页 | 会稀释资料查找主任务，并增加无效维护成本 |
