# 16 视觉素材生成对接单

> 这一页是「生图/生视频」专用的工作单。你给需求，我按此单登记、生成、归档。
> 素材落在 [`assets/generated/`](../assets/generated/)（下分 `images/`、`videos/`），本文件只做登记与验收，不放二进制。

## 工作流

1. **你给需求** → 我登记到下面的「需求队列」。
2. **生成前确认** → 我会先跟你核对：产出什么/几张、画幅尺寸、用到的参考素材，你点头才动手。
3. **生成** → 图走 `text_to_image` / `edit_image`，视频走 `text_to_video` / `frame_to_video`。有参考图一定带上，不做"像但不是同一个"的文字重绘。
4. **归档** → 每件产物存进 `assets/generated/images/` 或 `videos/`，登记「产出记录」，并上一张 `.miora` 画布供你直观看。
5. **验收** → 逐件核对内容与规格，写结论。不合格由你决定是否重做，我不会自动重来。

### DEEP-001 · 管理员桌面「行动中心」

**目标**：为 `/dashboard` 提供视觉方向，不直接当生产界面截图使用。**必须按 19 号规格组织内容。**

深空背景，12 列精密网格，左侧 64px 窄导航；顶栏放小字标 DEEP、学期班级、搜索与头像。页头是日期与「N 项待办 · 最近截止 HH:MM」，不要巨大 DEEP 字。主区域左 8 列为「现在要做」行动清单（完成按钮、标题、来源标签、时间、主动作），右 4 列为「接下来」48 小时时间轴；下方三张并列卡分别是「进行中的作业」「资料」「通知」，每张都有真实条目与主动作。轨道线稿只作页头低对比背景，不单独占大卡。

禁止出现：资料热度、下载排行、健康分、Status / Progress / Health / Next Node / Resource Heat、灰色横线假文字、为凑四宫格的统计数字、点名矩阵、大块空轨道卡、伪造百分比。

蓝表示进行中，金表示归位，红色最多一处且只给真 DDL 危机。中文正文、数字与按钮由前端实现，概念图只要求大标题可辨，不要求小字准确。避免：霓虹紫蓝、赛博城市、发光边框、满屏图表、玻璃叠玻璃、3D 机器人、夸张粒子、通用 Bootstrap 模板感。
