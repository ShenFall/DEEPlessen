# 24 学生端外观需求（交付视觉侧）

> 2026-11-23。对象：学生门户（`https://deep-portal.pages.dev`）。
> 现状：功能已通（搜索、分组、下载都验过），**只差外观**。改动方式是改 `app/src/storage/portal.ts` 里的 `PORTAL_HTML` 模板，改完重新导出部署。

## 0. 一句话

一个手机上的**取件柜**：打开、搜到、点一下就下载完。不需要登录，不需要教程。

## 1. 硬约束（先看这五条）

| 约束 | 数值 | 原因 |
|---|---|---|
| 单文件交付 | 一个 `index.html`，内联 CSS/JS | 部署方式是拖 zip，多文件容易断链 |
| 体积 | gzip 后 **< 6 KB** | 学生多数在 4G 下打开 |
| 零外部请求 | 不引字体、图标库、CDN、统计 | 断网/被墙时不能白屏 |
| 只读 | 无登录、无上传、无评论、无收藏 | 权限模型不存在，别假装有 |
| 数据来源 | 只读同目录 `manifest.json` | 结构见第 5 节 |

## 2. 页面结构（自上而下）

```
┌─────────────────────────────┐
│ 课程资料              ◜◝    │  ← 标题 + 轨道线稿（右上角出血）
│ 8 个文件 · 1 门课           │  ← 副标题，等宽数字
├─────────────────────────────┤
│ [ 搜索文件名或课程         ] │  ← 吸顶，滚动时不消失
├─────────────────────────────┤
│ 未分类  8 个文件             │
│ ┌─────────────────────────┐ │
│ │[PDF] 冬天到了…pdf  770KB  下载│ │
│ │[DOC] 入学登记表.doc 17KB  下载│ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│      更新于 11 月 23 日      │
└─────────────────────────────┘
```

## 3. 组件清单

### 3.1 头部

- 标题「课程资料」：24px / 600 / `-0.02em`
- 副标题：13px / 次色，格式 `8 个文件 · 1 门课`，未加载时显示「加载中…」
- **轨道线稿**：同心虚线圆 + 3 颗金色小点，右上角出血（top −70、right −60），直径 260，透明度 0.5
  - 只取「同心圆、细线、少量星点」三种语言
  - **禁止**：魔法阵、塔罗图腾、月相、捕梦网、任何神秘学意象

### 3.2 搜索

- 吸顶（`position: sticky; top: 0`），背景与页面同色，底部渐变淡出
- 高度 44，圆角 10，边框 1px `#E6E0D5`
- 聚焦：边框 `#CDBFA4`，外发光 `rgba(140,90,32,.08)` 3px
- 输入即过滤，**不做防抖、不做动画**

### 3.3 课程分组

- 组标题：`课程名` + 右侧 `N 个文件`，14px / 600，次色计数
- 一组一张卡（白底、1px 边框、圆角 12），组内行之间用 1px 分隔线
- 课程顺序：沿用 manifest 里的顺序，**不排序**

### 3.4 文件行

| 位置 | 内容 | 规格 |
|---|---|---|
| 左 | 类型徽章 | 38×38，圆角 9，底色 `#F0EBE1`，字 10px/600，金色，最多 4 字符（PDF / DOCX / PNG / ZIP） |
| 中上 | 文件名 | 14px / 500，**单行省略**，超长截断 |
| 中下 | 大小 | 12px，次色，等宽数字（`KB` / `MB` 保留一位小数） |
| 右 | 「下载」 | 12px，金色 |

- 整行可点，`<a download>` 直接下载，不做预览页
- hover 背景 `#FAF7F1`（120ms），active `#F3EEE4`
- 触控区高度 ≥ 62px

### 3.5 空态

| 场景 | 文案 | 样式 |
|---|---|---|
| manifest 缺失 | 「清单读不出来，请刷新页面」 | 副标题位置，次色 |
| 没有资料 | 「还没有资料」 | 居中，36px 上下留白 |
| 搜不到 | 「没有匹配的资料」 | 同上 |

## 4. 视觉 Token（不要新增颜色）

| 变量 | 值 | 用途 |
|---|---|---|
| 页面底 | `#F7F4EE` | 纸白 |
| 卡片 | `#FFFFFF` | 列表容器 |
| 分隔线 | `#E6E0D5` | 1px |
| 主文字 | `#1A1F2A` | 文件名 |
| 次文字 | `#616875` | 大小、副标题（已过 AA） |
| 强调 | `#8C5A20` | 下载、徽章文字（已过 AA） |
| 徽章底 | `#F0EBE1` | — |

- 字体：系统黑体栈，不加网络字体
- 圆角：卡片 12 / 输入 10 / 徽章 9
- 视觉方向：**克制**。背景可以有一层从右上往左下的极浅暖光，但不要渐变卡片、不要玻璃拟态、不要投影堆叠

## 5. 数据结构（只读，不改）

```json
{
  "generatedAt": "2026-11-23T18:50:00",
  "courses": [
    { "name": "未分类", "items": [
      { "name": "冬天到了 我想问你19个问题.pdf", "size": 789708, "url": "files/…/…pdf" }
    ]}
  ]
}
```

- `name` 可能含中文、空格、括号，渲染必须转义
- `url` 已 URL 编码，直接放进 `href`，不要二次编码
- `size` 是字节数，前端换算

## 6. 动效（可选，最多这几条）

| 动效 | 时长 | 缓动 | 数值 |
|---|---|---|---|
| 卡片入场 | 200ms | `cubic-bezier(.2,.8,.2,1)` | `opacity 0→1`，`translateY 6px→0`，最多 8 组，间隔 24ms |
| 行 hover | 120ms | `ease` | 背景色过渡 |
| 搜索过滤 | 0 | — | 直接替换，不加动画 |

`prefers-reduced-motion: reduce` 时全部关闭。

## 7. 禁项

- ❌ 深色主题（学生端固定纸白）
- ❌ 下载量、热度、浏览量、进度条
- ❌ 登录、头像、个人中心
- ❌ 参考图里的英文标题、水印、素材站字样
- ❌ 整张参考图当背景
- ❌ 引入 Tailwind / 任何 CDN 资源

## 8. 验收标准

1. **402×870** 下无横向滚动，下载按钮可点
2. 320px 窄屏下文件名省略、不换行溢出
3. 所有文字对比度 ≥ 4.5:1（次色 `#616875` 已达标）
4. 断网刷新 → 显示「清单读不出来」，不白屏
5. 首屏 `index.html` gzip < 6 KB，零外部请求
6. 中文、空格、括号文件名显示正常，点击可下载
7. 提供三张截图：1080 宽、402 宽、320 宽

## 9. 交付方式

| 方式 | 说明 |
|---|---|
| **改模板**（推荐） | 直接改 `app/src/storage/portal.ts` 的 `PORTAL_HTML`，我负责构建与导出 |
| **给独立文件** | 交一份 `index.html`，我合并进模板 |

改完我这边跑 `npm run build` → 你导出 → 打包 → Cloudflare 更新部署，**网址不变**。
